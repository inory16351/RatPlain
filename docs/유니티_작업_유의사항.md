# Unity 작업 유의사항 (2026-10-29)

Unity 작업을 시작하기 전에 반드시 읽을 것. 새 대화 · 에이전트 모두 해당.

## 환경
- 프로젝트: `unity/` (Unity **6000.3.19f1**, 2D URP 템플릿)
- MCP: **MCP for Unity** (`com.coplaydev.unity-mcp`, `unity/Packages/manifest.json`) + 저장소 루트 `.mcp.json` 의 `unityMCP` 서버 (`uvx --from mcpforunityserver mcp-for-unity --transport stdio`)
- 연결 확인: Unity 메뉴 **Window → MCP for Unity** 에서 브리지 켜짐 확인 → Claude Code 에서 `unityMCP` 도구가 보여야 함
- **빌드는 시키지 않으면 하지 않음** (에디터 열기 · 컴파일까지만)

## 오브젝트 생성 규칙 (가장 중요)
- 씬 오브젝트는 **MCP 로 하이라키에 직접 생성** (GameObject 만들기 · 컴포넌트 붙이기 · 값 설정 · 스프라이트 연결 · 자식 배치까지)
- **코드로 오브젝트 구성 하드코딩 금지**: 스크립트에서 `new GameObject` + `AddComponent` + 값 대입으로 씬 · UI · 적 · 탄 등을 조립하지 않음
- 예외 (허용): **하이라키 · 에셋에 있는 템플릿이나 프리팹 원본을 복제**해서 소환하는 코드
  - 예: 원본 프리팹을 MCP 로 만들어 두고 → 스크립트는 `[SerializeField]` 로 그 원본을 받아 `Instantiate` (탄 · 적 · 이펙트 · 드롭 아이템 · 목록 UI 행)
  - 복제 뒤 위치 · 방향 · 스탯 같은 **런타임 값**을 넣는 것은 괜찮음. 생김새 · 구조(컴포넌트 · 자식 · 스프라이트)는 원본에서 옴
- 원본이 아직 없으면: 코드부터 쓰지 말고 **MCP 로 원본(프리팹 또는 비활성 템플릿 오브젝트)부터 만든다**
- 스크립트가 할 일 = 동작(로직). 무엇이 어떻게 생겼는지 = 하이라키 · 프리팹 (MCP 로 만들고, 사람이 에디터에서 고칠 수 있게)

## 작업 순서
1. MCP 연결 확인 (`unityMCP` 도구 없으면 작업 멈추고 사용자에게 알림 — 하드코딩으로 대신하지 않음)
2. 필요한 스크립트 작성 → 컴파일 오류 확인 (MCP 콘솔 읽기)
3. MCP 로 하이라키에 오브젝트 · 프리팹 원본 생성, 스크립트 붙이고 참조 연결
4. 씬 · 프리팹 저장
5. 확인: 플레이 모드 · 콘솔 로그 (빌드 아님)
