## 1. 메인 로비 (가장 먼저)
- 로고 넣기: `pirate/art/itch/logo.png` (1444x929 투명 PNG, "PIRAT OF THE CARIBBEAN" + 해적모) → `Pirate_1/Assets/Art/UI/` 로 가져와 스프라이트로
- 버튼 4개: **이어하기 · 새 게임 · 설정 · 게임 종료**
  - 이어하기: 기록 있을 때만 (`Shipyard.HasSave`). 없으면 숨기거나 비활성
  - 새 게임: 기록 있으면 확인 창 뒤 `Shipyard.NewGame()` (기존 동작 그대로)
  - 설정: 설정 창 (최소 = 소리 켜기/끄기, `Sfx` 의 `mute` PlayerPrefs 재사용. 볼륨 슬라이더 있으면 더 좋음)
  - 게임 종료: `Application.Quit()`. WebGL 에선 종료가 안 되므로 WebGL 빌드에선 버튼 숨김 (`#if UNITY_WEBGL`)
- 배경 · 꾸밈: itch 그림체 맞춤. 참고 그림 `pirate/art/itch/cover_v2.png` · `bg_v2.png` (양옆 쥐 해적선 · 고양이 해군), 버튼은 기존 `ui_frames` 나무 판 스프라이트
- **이미 있는 것**: `Assets/Scripts/Port/TitleScreen.cs` = 타이틀 패널 (이어서 출항하기 / 새로 출항하기 + 새 게임 확인 창 `confirmPanel`) → 이야기 → 항구. 이걸 고쳐서 로비로 씀 (새로 만들지 말 것). 패널 · 버튼은 Port 씬 하이라키에 MCP 로 추가하고 TitleScreen 필드에 연결

## 2. ESC → "메인메뉴로 나가시겠습니까?" 확인 배너
- 문구: **메인메뉴로 나가시겠습니까?** 버튼 **예 / 아니오**
- 예 = 로비(타이틀 패널)로, 아니오 = 닫고 계속
- 항구 · 전투 둘 다. 전투(`GameManager.cs:148`)는 지금 Esc · P 가 일시정지 토글 → **Esc = 확인 배너(열려 있는 동안 일시정지), P = 일시정지 그대로**로 바꿈. 전투에서 예 = 전투 결과 없이 Port 씬 로드 후 로비 열기 (`TitleScreen.seenTitle` 같은 static 플래그로 로비 다시 띄움)
- 항구에서 다른 창(조선소 탭 · 확인 창 · 이야기)이 열려 있으면 Esc 는 그 창 닫기가 먼저, 아무것도 없을 때 확인 배너
- 배너 UI 는 프리팹 원본 하나를 MCP 로 만들어 두 씬에서 같이 씀

## 3. 확인 (빌드 아님)

## 4. WebGL 빌드 · itch 업로드 (사용자가 빌드하라고 할 때만)
- 빌드 스크립트 있음: `Assets/Editor/WebGLBuild.cs` (메뉴 Tools → Build WebGL (itch), 배치 `Unity.exe -batchmode -quit -buildTarget WebGL -projectPath Pirate_1 -executeMethod WebGLBuild.Build -logFile build/build_webgl.log`). 결과 `build/Pirate_1_WebGL` (gitignore), 웹 화면 1280x720 · 압축 해제 폴백 켬
- 첫 배치 빌드(11-03)는 emcc 가 C 파일 하나 컴파일하다 0xC0000005 로 죽음 → 일시적 크래시로 보임, 다시 돌리면 됨 (Bee 증분)
- 그 실패한 빌드가 Unity 설정 파일을 바꿔 놓았음, 커밋 안 함: `Assets/Settings/UniversalRP.asset` · `Assets/UniversalRenderPipelineGlobalSettings.asset` · `ProjectSettings/GraphicsSettings.asset` · `ProjectSettings.asset` · `ShaderGraphSettings.asset`, 그리고 새 파일 `Assets/Resources/PerformanceTestRunInfo.json` · `PerformanceTestRunSettings.json`. 에디터 열면 다시 생길 수 있으니 diff 보고 필요한 것만 커밋
- Product Name 을 "Pirat of the Caribbean" 으로 (지금 `Pirate_1`)
- 업로드: `build/Pirate_1_WebGL` 폴더 안 내용(index.html 이 zip 루트)을 zip → itch 편집 페이지 Uploads → "This file will be played in the browser" 체크 → 임베드 크기 1280x720 · Fullscreen 버튼 켬. 크롬 확장 업로드는 한 번에 10MB 까지라 넘으면 butler 쓰거나 사용자가 직접 올림
