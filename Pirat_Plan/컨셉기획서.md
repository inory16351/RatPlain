## 기획의도
- 원작의 가볍고 캐쥬얼한 감성을 살린 ip 확장 게임. 쥐 비행기 게임과 같은 뼈대를 바다로 옮긴 자매작
- 원작 해적 쥐(애꾸 · 삼각모)를 따 와서 ip 확장. 본편과는 별개 게임, 캐릭터와 그림체만 공유
- 판 안에서는 선원 구조 · 콤보로 그 판만의 성장, 판 밖에서는 배 · 장비 누적 성장
- 배 성능이 낮아도 컨트롤로 깰 수 있는 구조 유지 (쥐 비행기 게임 원칙). 해적에서는 "배 몰기"가 그 컨트롤
- 뱃전 일제 사격 = 옆구리를 적에게 돌려야 쏨 → 비행 슈팅과 다른 위치 잡기 재미
- 실제 배 발전 순서대로 진화 (갤리선 → 범선 → 증기선 → 강철 군함 → 현대 함정) → 모으는 재미 + 눈에 보이는 변화

- 바다 흐름 (예시): 항구 앞바다 → 상어 암초 → 고양이 해군 순찰대 → 해적 소굴 → 폭풍 해협 → … → 고양이 해군 본진
- 배도 노 젓는 갤리선 → 항공모함 · 잠수함 · 미사일 고속정 순으로 변화



## 스토리
- 주인공: 원작 해적 쥐 "애꾸 선장" (애꾸 안대 · 삼각모 · 빨간 코트)
- 고양이 해군에게 빼앗긴 바다를 되찾고 일곱 바다를 정복하겠다는 야망
- 첫 배 = 애꾸 선장이 처음 훔친 노 젓는 갤리선
- 조력자: 조선공 쥐. 항구에서 배를 고치고 장비를 만듦 (비행기 게임의 과학자 쥐 자리)
- 적 세력
	- 고양이 해군: 바다를 장악한 정규군. 작은 순찰선에서 시작해 해상 요새까지 점점 강해짐
	- 라이벌 쥐 해적: 같은 쥐지만 바다를 노리는 경쟁자. 이름 있는 라이벌 선장이 보스로 반복 등장
	- 상어: 어느 세력에도 속하지 않는 바다의 위협. 물속에 숨어 지느러미만 보임
- 바다마다 짧은 스토리 문구, 최종 목표 = 고양이 해군 본진 격파

## 핵심 재미
- 배를 모는 손맛: 돛으로 속도, 키로 방향 조절. 옆구리를 적에게 돌려 일제 사격하는 위치 잡기가 곧 실력
- 격파의 쾌감: 뱃전 대포 여러 문이 한 번에 터지는 일제 사격, 콤보, 히트스톱, 화면 흔들림
- 구하면 강해지는 배: 물에 빠진 쥐를 건지면 선원 증가 → 장전 빨라짐 + 갑판에 선원이 늘어나는 게 보임
- 바다에 맞춰 고르는 배: 바다마다 적 조합 · 맵 특성이 달라 갈래가 다른 배와 장비를 골라 출항
- 진화하는 배: 갤리선에서 항공모함까지 실제 배 역사 순서로 성장. 단계마다 자동 무기가 붙어 전투 양상 변화

## 게임 루프
- 판 안: 웨이브 전투 → 웨이브 사이 수리 (선원 수만큼 추가) → 다음 웨이브 → … → 보스 → 클리어 보상
- 웨이브마다 보물상자 등장, 화면 가장자리 화살표 · 미니맵으로 위치 표시
- 판 밖(항구): 목재 / 치즈 금화로 배 구매, 조선소 의뢰, 합성 → 바다 특성에 맞는 배 선택 → 재출항
- 침몰해도 모은 재화 일부 회수. 다시 출항할 이유 유지
- 바다 클리어 시 다음 바다 개방

## 인게임 시스템
- 상세: 전투 기획서

### 조작 / 전투
- 키보드로 배를 몰고 마우스로 쏠 쪽을 고르는 구조 (예시 배치)

| 입력 | 동작 |
|---|---|
| W / S | 돛 올리기 · 내리기 (속도) |
| A / D | 키 (방향 전환) |
| 왼쪽 클릭 (누르고 있으면 연사) | 마우스 쪽 뱃전 일제 사격 |
| Q / E | 왼쪽 / 오른쪽 뱃전 일제 사격 |
| Space | 양쪽 뱃전 동시 사격 |
| 1 / 2 / 3 | 특수탄 · 폭격 (예: 체인샷 = 적 돛을 찢어 느리게, 화염탄 = 지속 피해, 폭격 = 마우스 위치 광역) |

- 특수탄 · 폭격은 해당 능력이 있는 배 · 장비에서만 사용 가능
- 대포 쿨다운은 좌우 따로
- 전투 수치는 배 + 장비 계산 결과 사용: 대포 수 · 장전 · 위력 · 치명타 · 사거리 · 속도 · 회전 · 선체 · 받는 피해 등
- 콤보: 일정 시간 안에 연속 격침 시 이어짐. 콤보가 쌓이면 금화 획득량 상승
- 떨어뜨리는 것: 치즈 금화 · 목재 · 보물상자 · 납치된 쥐(구조 = 선원 +1)
- 바다 · 섬 · 물살 · 파편 · 콤보 · 히트스톱 연출
- 포탄 물리: 포탄은 배 속도 + 회전 선속도를 이어받음, 쏘면 반동으로 옆으로 밀림, 바람이 포탄도 밂
- 조준선: 대포 한 문마다 실제 날아갈 길 점선으로 표기 + 착탄 지점 원형 범위로 표시 (발사 계산과 같은 식). 경로와 착탄 지점은 색으로 구분 (적 = 빨강, 플레이어 = 금빛)
- 무한 확장 방식의 맵 설계: 경계 없음. 일정 칸마다 섬 · 장식 생성, 멀어지면 해당 값은 저장하지 않고 삭제. 너무 멀어진 적은 배 근처로 다시 등장
- 미니맵: 배가 가운데인 레이더 형식으로 표현

### 자동 무기
- 배 단계가 오르면 자동 무기가 붙음 → 조작 부담은 그대로, 화력만 추가
- 시대가 바뀌는 게 전투에서 바로 느껴지게 하는 장치 (예: 증기선 = 선수포, 강철 군함 = 어뢰, 현대 = 유도탄 · 함재기)
- 장비로 자동 무기를 강화하거나 새로 붙이는 빌드 가능 (예: 자동 폭격)
- 갈래마다 다른 자동 무기 → 같은 시대라도 갈래별로 싸우는 방식이 다름

### 선원
- 구조: 격침된 배에서 쥐가 물에 빠짐 → 지나가며 건지면 선원 +1
	- 선원 1명당 장전 속도 증가, 최대 선원 수는 테크에 따라 상승
	- 판 안에서만 유지. 판이 끝나면 초기화
- 리깅: 배 그림과 선원 그림을 분리. 배 갑판은 비워 두고 선원을 따로 올림
	- 배마다 선원 자리를 정해 두고 건진 수만큼 차례로 채움 → 선원 수가 눈으로 보임
	- 선장: 고물 쪽 고정, 쏠 때 칼로 가리킴. 시대가 바뀌면 옷도 바뀜
	- 선원은 유닛처럼 반응: 사격 때 대포 쪽으로 달려가 장전, 맞으면 움찔, 격침하면 만세
	- 고양이 배 = 고양이 수병, 보스 = 전용 선장
	- 장점: 배 그림 하나로 선원 수 변화 · 반응 연출 가능, 그림 생성 수 감소

### 몬스터
- 접근이 안전한 적과 거리를 둬야 하는 적을 섞어서 위치 선정이 곧 실력이 되는 구조
- 강한 공격은 예고선 / 예고 원으로 반드시 사전 표시 (쥐 비행기 게임과 같은 원칙)
- 적 구성 (예시)

| 적 | 소속 | 행동 | 대처 |
|---|---|---|---|
| 순찰선 | 고양이 해군 | 뱃전 일제 사격 | 측면 피해 선수 · 선미 쪽으로 접근 |
| 프리깃 | 고양이 해군 | 대포 많은 일제 사격 | 체인샷으로 늦춘 뒤 측면 사격 |
| 쾌속정 | 고양이 해군 | 빠르게 달려와 박치기 | 키 꺾어 회피, 선수포 · 박치기 장비 |
| 박격포선 | 고양이 해군 | 느림, 곡사 폭격 | 예고 원 이탈 후 접근 |
| 철갑함 | 고양이 해군 | 단단함, 회전 포탑 | 고위력 포 · 어뢰 · 폭격 |
| 라이벌 쥐 해적선 | 라이벌 쥐 해적 | 쥐 해적처럼 일제 사격 | 같은 방식의 측면 싸움 |
| 상어 | 상어 | 잠수 접근 후 떠올라 물기 | 떠오른 순간 사격, 어뢰 · 폭격 |
| 떠다니는 폭탄통 | - | 거의 안 움직임, 닿으면 폭발 | 멀리서 사격 |

- 상어 = 이 게임만의 적. 평소엔 지느러미만 보이는 잠수 상태라 포탄이 안 맞음
	- 공격 뒤 지쳐서 멈추는 틈 = 반격 타이밍. 어뢰 · 폭격 갈래는 잠수 중에도 공격 가능
	- 갈래별 배의 차이가 드러나는 적

### 바다 / 보스
- 바다 스테이지 = 웨이브 주기 + 보스. 웨이브 사이 수리
- 바다마다 주력 세력 · 적 조합이 다름 → 바다에 맞는 배를 골라 가는 이유
- 뒤쪽 바다로 갈수록 적 강화 (난이도 배율). 바다마다 추천 배 단계 표시
- 보스는 세력마다 성격이 다른 패턴 (예: 라이벌 선장 = 일제 사격 + 화염, 거대 상어 = 잠수 → 돌진 → 지침, 고양이 제독 = 폭격 세례 + 쾌속정 소환)
- 앞에서 만난 보스가 강화판으로 다시 등장 → 성장 체감 + 보스 수 대비 볼륨 확보

### 맵 특성
- 4번째 바다쯤부터 맵 특성 등장. 배 하나만으로는 한계 → 여러 갈래 배 육성 유도
- 예시: 안개(시야 제한 → 망원경 · 레이더가 힘), 폭풍(바람에 밀림 + 번개 → 날씨 저항), 소용돌이(가운데로 끌어당김 → 빠른 배 · 날씨 저항)

## 아웃게임 시스템
- 기본적인 설명은 해줘야함

### 배 진화
- 실제 배 발전 순서대로 테크를 강화화
- 시대 (예시): 고대 → 대항해시대 → 범선 전성기 → 증기선 시대 → 강철 군함 → 현대
- 이전 단계 배 보유 시 다음 배 구매 가능. 구매한 배는 자유롭게 교체
- 테크 = 보유 배 최고 단계. 테크가 오르면 새 장비 티어 · 의뢰 목표 열림

| 갈래 | 성격 | 진화 (예시) |
|---|---|---|
| 쾌속선 | 빠르고 잘 돎, 박치기 · 선수포 · 어뢰 · 유도탄 | 캐러벨 → 클리퍼 → 외륜 증기선 → 어뢰정 → 미사일 고속정 |
| 다목적함 | 균형형, 특수탄 · 폭격 · 선원 | 캐랙 → 프리깃 → 증기 프리깃 → 방호 순양함 → 잠수함 |
| 중포함 | 느리고 튼튼함, 대포 많음 · 피해 감소 | 갤리온 → 전열함 → 철갑함 → 드레드노트 → 항공모함 |

- 시작 배: 갤리선. 이 배의 장비는 모든 갈래에 장착 가능
- 배 단계가 오르면 장비 슬롯 증가, 장착 가능 티어 확장
- 슬롯 종류 (예시): 대포, 돛 · 기관, 선체 장갑, 키, 망원경, 선수상, 박격포, 특수탄 창고, 선원실
	- 배마다 슬롯 구성이 달라 배 성격 형성 (예: 쾌속선 = 키 · 선수상 중심, 중포함 = 선원실 · 박격포 중심)

### 장비
- 장비 = 티어 + 장착 가능 배(갈래) + 등급
- 장착 조건: 보유 배 + 해당 슬롯 보유 + 갈래 일치 + 배 단계 ≥ 장비 티어. 낮은 티어 장비는 상위 배에 장착 가능
- 장비 1개당 배 1척에만 장착 (다른 배로 이동 가능)
- 일반 / 고급 = 그 배의 기술 이름으로 만든 장비 (예: 갤리선 "청동 소포", 드레드노트 "14인치 주포")
- 희귀 / 전설 = 배마다 고유 장비. 일부는 다른 갈래에도 장착 가능
- 등급이 높을수록 고유 효과 부여
	- 일반: 수치 하나 상승
	- 고급: 상승폭 증가 또는 두 가지 동시 상승
	- 희귀: 고유 효과 시작 (예: 포탄이 맞은 곳 폭발, 일정 확률로 불붙임)
	- 전설: 플레이 방식 변화 (예: 일제 사격 한 번 더, 격침 시 회복, 함재기 추가)
- 갈래 · 시대 테마를 이름과 효과에 그대로 담음 (예: 클리퍼 "쇠뿔 생쥐 선수상" = 박치기, 항공모함 "하늘 치즈성 문장" = 함재기)

### 조선소 의뢰 / 합성 / 티어 업
- 상점 없음. 조선공 쥐에게 제작 의뢰 → 재화 소모, 일정 확률로 장비 획득
- 투입 재화를 슬라이더로 직접 결정. 많이 쓸수록 상위 등급 확률 증가. 확률은 화면에 그대로 공개
- 장비 티어는 테크 기준으로 등장 (테크에 가까울수록 높은 확률)
- 보유 배에 장착 가능한 장비만 등장
- 합성: 같은 티어 / 같은 등급 여러 개 → 한 등급 위 1개
- 티어 업: 같은 티어 전설 여러 개 → 한 티어 위 전설. 많이 넣을수록 성공 확률 상승, 실패 시 일부만 남음
- 티어 업은 한 단계 위 배 보유 필요 → 테크 상승마다 새 의뢰 / 도전 목표 발생
- 쥐 비행기 게임 연구 의뢰와 같은 구조 → 두 게임 경험이 이어짐

### 재화 순환
| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 목재 | 격침 · 보물상자 | 배 구매, 의뢰 |
| 치즈 금화 | 격침 · 보물상자 · 콤보 | 배 구매, 의뢰 |
| 선원 | 물에 빠진 쥐 · 납치된 쥐 구조 | 판 안 장전 단축 · 수리 (판 종료 시 소멸) |

- 항해 끝: 승리 = 모은 재화 전부 + 다음 바다 개방, 침몰 = 일부만
- 금화 / 목재 보너스 장비로 재화 수급 빌드 가능
- 흐름: 출항 → 재화 획득 → 배 구매 · 의뢰 → 테크 상승 → 상위 티어 장비 등장 → 다음 바다

### 항구 화면
| 탭 | 내용 |
|---|---|
| 출항 | 바다 지도 · 추천 배 단계 · 스토리 |

## 비쥬얼 가이드
- 원작의 플랫하고 귀여운 그림체 유지
- 차분한 색: 채도 낮은 자연색(나무 갈색 · 크림 · 탁한 빨강 / 파랑), 큰 면, 소품 최소, 외곽선 · 광택 · 그라데이션 없음
- 그림은 전부 탑뷰, 뱃머리 오른쪽 (회전은 코드 처리). 캐릭터만 살짝 내려다보는 쿼터뷰
- 배 그림만 봐도 쥐 · 고양이 구분 가능해야 함 (작게 봐도 읽히는 큰 형태)

| 세력 | 배 디자인 |
|---|---|
| 쥐 해적 (플레이어) | 쥐 머리 선수상 · 꼬리 모양 키 · 빨간 깃발에 치즈 조각 + 뼈 문양 · 치즈 색 포인트 |
| 고양이 해군 | 고양이 귀 뱃머리 · 발바닥 문양 돛 · 줄무늬 꼬리 키, 남색 + 크림 + 탁한 금색 |
| 라이벌 쥐 해적 | 회색 쥐 해골 문양 검은 돛 · 회색 쥐 선수상 · 숯색 + 검붉은 나무 |
| 상어 | 귀엽지만 위협적인 탑뷰, 잠수용 지느러미 그림 별도 |

- 해적기 문양: 세 동그라미 쥐 귀 실루엣 사용 금지 (유명 만화 쥐 로고처럼 보임) → 치즈 조각 + 뼈
- 배 갑판은 비워 둠 (선원은 리깅으로 따로 올림)
- 포탄 · 연기 · 물살은 벡터 이펙트, 위험 요소는 예고선 / 예고 원으로 표시
- 바다는 이음매 없는 한 장 (단색 + 큰 얼룩 + 물결), 섬 · 장식만 그림
