## 기획의도
- 원작 해적 쥐 캐릭터를 활용한 캐쥬얼 해전 액션
- 원작 ip 확장: 원작 해적 쥐(애꾸 · 삼각모)가 주인공. 캐릭터 · 그림체만 공유하는 별개 게임, 캐릭터를 통한 ip 확장 시도
- 컨트롤 중심 전투: 옆구리를 돌려야 쏘는 측면 일제 사격. 배 성능이 낮아도 컨트롤로 클리어
- 인게임 · 아웃게임 성장: 인게임 = 선원 구조 · 콤보, 아웃게임 = 배 · 장비 강화
- 실제 함선 역사 순서로 강화: 갤리선 → 범선 → 증기선 → 강철 군함 → 현대 함정, 단계별 외형 · 무장 변화

- 스테이지 흐름 (예시): 항구 앞바다 → 상어 암초 → 고양이 해군 순찰대 → 해적 소굴 → 폭풍 해협 → … → 고양이 해군 본진
- 함선은 노 젓는 갤리선부터 항공모함 · 잠수함 · 미사일 고속정까지 변화

## 스토리
- 갤리선 한 척으로 시작하는 바다 정복. 고양이 해군에게 빼앗긴 바다 탈환 및 일곱 바다 정복이 목표
- 애꾸 선장: 애꾸 안대 · 삼각모 · 빨간 코트의 해적 쥐, 주인공
- 시작: 밤 항구에서 노 젓는 갤리선을 훔쳐 출항
- 조선공 쥐: 항구에서 함선 수리 · 장비 제작 담당
- 최종 목표: 고양이 해군 본진 격파, 스테이지마다 짧은 스토리 문구 노출

## 세력
- 4개 세력 구성. 세력별로 함선 · 공격 방식이 달라 스테이지마다 다른 전투 경험

| 세력 | 설명 |
|---|---|
| 쥐 해적 (플레이어) | 애꾸 선장과 선원. 쥐 머리 선수상 · 치즈 해적기 |
| 고양이 해군 | 바다를 장악한 정규군. 순찰선에서 해상 요새까지 |
| 라이벌 쥐 해적 | 같은 바다를 노리는 경쟁 해적. 네임드 선장이 보스로 재등장 |
| 상어 | 중립 위협 요소. 평소에는 지느러미만 노출 |

## 핵심 재미
- 컨트롤을 통해 험난한 바다를 돌파하라
- 컨트롤의 재미: 돛으로 속도, 키로 방향 조절. 적에게 측면을 돌리는 위치 선정이 핵심
- 격파의 쾌감: 여러 문이 동시에 발사되는 일제 사격, 콤보 · 히트스톱 · 화면 흔들림 연출
- 인게임 강화요소: 물에 빠진 쥐 구조 시 선원 +1. 장전 속도 상승, 갑판 선원 수 증가
- 전략적 선택: 스테이지별 적 · 맵 특성에 맞춰 함선과 장비를 선택해 출항
- 아웃게임 강화요소: 갤리선부터 항공모함까지 함선 강화, 단계별 자동 무기 추가

## 게임 루프
- 보물을 획득하고, 함선을 강화하여 재출항
- 인게임 (스테이지): 웨이브 전투 → 수리 (선원 수만큼 추가) → 다음 웨이브 → 보스 → 클리어 보상
- 아웃게임 (항구): 함선 구매 → 조선소 의뢰 → 합성 · 티어 업 → 스테이지에 맞는 함선 선택 → 재출항
- 웨이브마다 보물상자 등장 (화살표 · 미니맵 표시)
- 침몰 시 재화 일부 회수, 클리어 시 다음 스테이지 개방

## 인게임 시스템
### 조작 / 전투
- 키보드를 통한 조작, 마우스로 방향을 선택 (예시 배치)

| 입력 | 동작 |
|---|---|
| W / S | 돛 (속도) |
| A / D | 키 (방향) |
| 왼쪽 클릭 (누르고 있으면 연사) | 마우스 방향 측면 사격 |
| Q / E | 왼쪽 · 오른쪽 측면 사격 |
| Space | 양쪽 동시 사격 |
| 1 / 2 / 3 | 체인샷 (적 돛을 찢어 감속) · 화염탄 (지속 피해) · 폭격 (마우스 위치 광역) |

- 특수탄 · 폭격은 해당 능력이 있는 함선 · 장비에서만 사용 가능
- 좌우 대포 쿨다운 별도, 전투 수치는 함선 + 장비 합산: 대포 수 · 장전 · 위력 · 치명타 · 사거리 · 속도 · 회전 · 선체 · 받는 피해 등
- 콤보: 일정 시간 안에 연속 격침 시 이어짐. 콤보가 쌓이면 금화 획득량 상승
- 드롭: 치즈 금화 · 목재 · 보물상자 · 납치된 쥐 (구조 시 선원 +1)
- 바다 · 섬 · 물살 · 파편 · 콤보 · 히트스톱 연출
- 포탄 물리: 함선 속도 · 회전 반영, 발사 반동으로 밀림, 바람이 포탄도 밂
- 조준선: 대포별 탄도 점선 · 착탄 지점 표시 (적 빨강, 플레이어 금색)
- 무한 바다: 맵 경계 없음, 구역마다 섬 생성 · 멀어지면 삭제. 너무 멀어진 적은 함선 근처로 재등장
- 레이더 미니맵: 함선 중심 레이더로 적 · 보물 위치 표시

### 자동 무기
- 조작방식은 유지, 아웃게임 강화를 통해 화력을 더함
- 시대 변화를 전투에서 바로 체감하도록 설계

| 시대 (예시) | 자동 무기 |
|---|---|
| 증기선 시대 | 선수포: 전방 적 자동 사격 |
| 강철 군함 | 어뢰: 잠수한 상어까지 공격 가능 |
| 현대 | 유도탄 · 함재기: 자동 추적 공격 |

- 테크별로 다른 자동 무기, 장비로 강화 · 추가 가능 (예: 자동 폭격)

### 선원
- 물에 빠진 쥐 구조 시 선원 +1, 장전 속도 상승 (해당 출항에서만 유지)
	- 최대 선원 수는 함선 단계에 따라 상승
- 함선과 선원 그림 분리, 구조한 선원이 갑판에 표시
	- 함선마다 선원 자리를 정해 두고 구조한 수만큼 차례로 배치
	- 선장: 고물 쪽 고정, 사격 시 칼로 지시. 시대별로 의상 변화
	- 사격 시 장전 이동, 피격 시 움찔, 격침 시 만세 모션
	- 고양이 함선은 고양이 수병, 보스는 전용 선장
	- 함선 그림 하나로 선원 수 변화 · 반응 연출 가능, 그림 제작량 감소

### 몬스터
- 패턴을 파악하여 전략적 위치 선점
- 강한 공격은 예고선 · 예고 원으로 사전 표시
- 적 구성 (예시)

| 적 | 소속 | 행동 | 대처 |
|---|---|---|---|
| 순찰선 | 고양이 해군 | 측면 일제 사격 | 선수 · 선미 쪽으로 접근 |
| 프리깃 | 고양이 해군 | 대포 많은 일제 사격 | 체인샷으로 늦춘 뒤 측면 사격 |
| 쾌속정 | 고양이 해군 | 돌진 후 박치기 | 방향 전환으로 회피 · 선수포 |
| 박격포선 | 고양이 해군 | 느림, 곡사 폭격 | 예고 원 이탈 후 접근 |
| 철갑함 | 고양이 해군 | 단단함, 회전 포탑 | 고위력 포 · 어뢰 · 폭격 |
| 라이벌 해적선 | 라이벌 쥐 해적 | 플레이어와 같은 측면 일제 사격 | 측면 사격 대결 |
| 상어 | 상어 | 잠수 접근 → 떠올라 물기 | 공격 후 멈춘 틈에 반격 |
| 폭탄통 | 중립 | 떠다니다 닿으면 폭발 | 멀리서 사격 |

- 상어: 평소 지느러미만 노출된 잠수 상태라 포탄 무효
	- 공격 후 멈추는 틈이 반격 타이밍. 어뢰 · 폭격 테크는 잠수 중에도 공격 가능
	- 테크별 함선 차이가 드러나는 적

### 스테이지 / 보스
- 스테이지마다 다른 세력 · 보스 · 날씨
- 스테이지는 웨이브 + 보스 구성, 웨이브 사이 수리
- 스테이지마다 주력 세력 · 적 조합이 달라 스테이지에 맞는 함선 선택 유도
- 후반일수록 난이도 상승, 스테이지마다 추천 함선 단계 표시
- 보스 (예시): 라이벌 선장 = 일제 사격 + 화염, 거대 상어 = 잠수 → 돌진 → 지침, 고양이 제독 = 폭격 세례 + 쾌속정 소환, 해상 요새 = 포탑 사격 · 폭격 비 · 소환
- 이전 보스 강화판 재등장 → 성장 체감 + 보스 수 대비 볼륨 확보

### 맵 특성
- 4번째 스테이지부터 등장, 여러 테크 육성 유도

| 맵 특성 (예시) | 효과 | 유리한 쪽 |
|---|---|---|
| 안개 | 시야 제한 | 망원경 · 레이더 장비 |
| 폭풍 | 바람에 밀림 + 번개 | 날씨 저항 장비 |
| 소용돌이 | 중심으로 끌어당김 | 빠른 함선 · 날씨 저항 |

## 아웃게임 시스템
### 개요
- 인게임에서 모은 재화로 항구에서 배와 장비를 강화
- 흐름: 출항 → 재화 획득 → 함선 구매 · 의뢰 → 함선 단계 상승 → 상위 장비 등장 → 다음 스테이지
- 보유 함선 단계가 오를수록 상위 장비 · 고난도 스테이지 개방
- 항구 = 아웃게임 화면. 출항 · 조선소 · 장비 · 의뢰 / 합성 4개 탭으로 구성

### 함선 강화
- 실제 배 발전 순서대로 아웃게임 함선 강화
- 시대 (예시): 고대 → 대항해시대 → 범선 전성기 → 증기선 시대 → 강철 군함 → 현대
- 이전 단계 함선 보유 시 다음 함선 구매 가능, 구매한 함선은 자유 교체
- 함선 단계가 오르면 새 장비 티어 · 의뢰 목표 개방

| 테크 | 성격 | 함선 (예시) |
|---|---|---|
| 쾌속선 | 빠른 속도 · 선회, 박치기 · 어뢰 · 유도탄 | 캐러벨 → 클리퍼 → 외륜 증기선 → 어뢰정 → 미사일 고속정 |
| 다목적함 | 균형형, 특수탄 · 폭격 · 선원 | 캐랙 → 프리깃 → 증기 프리깃 → 방호 순양함 → 잠수함 |
| 중포함 | 느리지만 튼튼함, 대포 많음 · 피해 감소 | 갤리온 → 전열함 → 철갑함 → 드레드노트 → 항공모함 |

- 시작 함선 갤리선의 장비는 모든 테크에 장착 가능
- 단계가 오르면 장비 슬롯 · 장착 가능 티어 확장

### 장비
- 장비 = 티어 + 장착 가능 함선 + 등급
- 함선마다 슬롯 구성이 달라 함선 개성 형성, 등급이 높을수록 고유 효과 부여
- 슬롯 종류 (예시): 대포, 돛 · 기관, 선체 장갑, 키, 망원경, 선수상, 박격포, 특수탄 창고, 선원실
- 장착 조건: 보유 함선 + 해당 슬롯 + 테크 일치 + 함선 단계 ≥ 장비 티어. 낮은 티어 장비는 상위 함선에 장착 가능
- 장비 1개당 함선 1척 (이동 가능)
- 일반 / 고급: 해당 함선의 기술 이름으로 만든 장비 (예: 갤리선 "청동 소포", 드레드노트 "14인치 주포")
- 희귀 / 전설: 함선마다 고유 장비, 일부는 다른 테크에도 장착 가능

| 등급 | 성격 | 예시 |
|---|---|---|
| 일반 | 수치 하나 상승 | 갤리선 "청동 소포": 포탄 위력 상승 |
| 고급 | 상승폭 증가 또는 두 가지 동시 상승 | 대포: 위력 + 장전 동시 상승 |
| 희귀 | 고유 효과 부여 | 착탄 지점 폭발 · 확률 화염 |
| 전설 | 플레이 방식 변화 | 일제 사격 추가 발사 · 격침 시 회복 · 함재기 추가 |

- 이름 · 효과에 테크 · 시대 테마 반영 (예: 클리퍼 "쇠뿔 생쥐 선수상" = 박치기, 항공모함 "하늘 치즈성 문장" = 함재기)

### 조선소 의뢰 / 합성 / 티어 업
- 조선공 쥐를 통한 장비 제작. 상점 없음
- 제작 의뢰: 투입 재화를 슬라이더로 결정, 많이 투입할수록 상위 등급 확률 상승. 확률은 화면에 전부 공개
- 합성: 같은 티어 · 같은 등급 여러 개 → 한 등급 위 1개
- 티어 업: 같은 티어 전설 여러 개 → 한 티어 위 전설. 투입 수가 많을수록 성공 확률 상승, 실패 시 일부만 반환
- 보유 함선에 장착 가능한 장비만 등장 · 현재 단계에 가까운 티어일수록 등장 확률 상승
- 티어 업은 한 단계 위 함선 보유 시 도전 가능, 단계 상승마다 새 목표 발생

### 재화 순환
| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 목재 | 격침 · 보물상자 | 함선 구매 · 의뢰 |
| 치즈 금화 | 격침 · 보물상자 · 콤보 | 함선 구매 · 의뢰 |
| 선원 | 빠진 쥐 · 납치된 쥐 구조 | 인게임 장전 · 수리 (출항 종료 시 초기화) |

- 클리어 시 재화 전부 + 다음 스테이지 개방, 침몰 시 일부만 회수
- 금화 / 목재 보너스 장비로 재화 수급 빌드 가능

### 항구 화면
| 탭 | 내용 |
|---|---|
| 출항 | 스테이지 지도 · 추천 함선 · 스토리 |
| 조선소 | 함선 트리 · 구매 / 교체 |
| 장비 | 슬롯 장착 · 수치 비교 |
| 의뢰 / 합성 | 확률 공개 · 티어 업, 조선공 쥐 망치질 연출 |

- 함선 요약 수치 (예: 선체 · 속도 · 측면 대포 · 장전 · 화력) 상시 표시로 장비 비교

## 비쥬얼 가이드
- 원작의 플랫하고 귀여운 그림체
- 전부 탑뷰 · 뱃머리 오른쪽 (회전은 코드 처리), 캐릭터만 살짝 쿼터뷰
- 한 색 + 그림자 한 단, 외곽선 · 광택 · 그라데이션 없음
- 채도 낮은 자연색 (나무 · 크림 · 탁한 빨강 · 탁한 남색 · 바다 · 흐린 금색), 큰 면, 소품 최소
- 함선만 봐도 쥐 · 고양이 구분 가능 (선수상 · 돛 · 꼬리 키)

| 세력 | 함선 디자인 |
|---|---|
| 쥐 해적 (플레이어) | 쥐 머리 선수상 · 꼬리 키 · 치즈 해적기 |
| 고양이 해군 | 고양이 귀 뱃머리 · 발바닥 돛 · 남색 |
| 라이벌 쥐 해적 | 해골 검은 돛 · 숯색 나무 |
| 상어 | 평소 지느러미만 노출, 공격 시 몸 전체 노출 |

- 해적기는 치즈 + 뼈 문양 (세 동그라미 쥐 귀 실루엣 금지)
- 함선 갑판은 비우고 선원은 별도 배치
- 위험 요소는 예고선 · 예고 원, 포탄 · 연기 · 물살은 벡터 이펙트
- 바다는 이음매 없는 한 장 (단색 + 큰 얼룩 + 물결), 섬 · 장식만 그림
