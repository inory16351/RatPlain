# 개요
## 기획의도
- 인게임에서 모은 재화로 항구에서 함선과 장비를 강화하여 다음 스테이지 돌파
- 실제 배 발전 순서대로 함선이 바뀌어 성장을 눈으로 체감
- 스테이지마다 적 · 맵 특성이 상이 -> 테크가 다른 함선 · 장비를 골라 출항하는 전략적 선택 부여

## 강화 흐름
- 출항 → 재화 획득 → 함선 구매 · 조선소 의뢰 → 함선 단계 상승 → 상위 티어 장비 등장 → 다음 스테이지
- 함선 단계 = 보유 함선 중 최고 단계. 단계가 오를수록 상위 장비 · 고난도 스테이지 개방
- 함선 강화는 테크 트리 구매 방식만 사용. 같은 함선의 레벨 강화 없음

## 항구 화면
| 탭 | 내용 |
|---|---|
| 출항 | 스테이지 지도 · 추천 함선 단계 · 스토리 |
| 조선소 | 함선 테크 트리, 함선 구매 · 교체, 수치 미리보기 |
| 장비 | 함선별 슬롯 장착 · 해제, 장착 전후 수치 비교, 장착 불가 사유 표시 |
| 의뢰 · 합성 | 제작 의뢰 · 합성 · 티어 업 · 분해, 조선공 쥐 망치질 연출 |

- 함선 요약 수치 (예: 선체 · 속도 · 측면 대포 · 장전 · 화력 · 받는 피해) 상시 표시

# 함선 강화
## 기획의도
- 현실 배 발전 순서를 따라가는 테크 트리로 수집의 재미 + 외형의 변화로 피드백 전달
- 각 테크로 갈라져 같은 시대라도 테크별로 전투 방식이 변화 -> 선택의 재미 전달

## 세부 시스템
- 6시대 × 3테크 구성, 시작 함선 갤리선에서 3테크로 분기
- 이전 단계 함선 보유 시 다음 함선 구매 가능 (목재 + 치즈 금화 소모)
- 구매한 함선은 계속 보유, 출항 전 자유 교체. 판매 · 환불 불가
- 함선 단계가 오를수록
	- 기본 수치 상승 (선체 · 측면 대포 수 등)
	- 장비 슬롯 증가 (예: 갤리선 3칸 → 현대 함선 7칸)
	- 자동 무기 추가 (예: 증기선 = 선수포, 강철 군함 = 어뢰, 현대 = 유도탄 · 함재기)
	- 장착 가능 장비 티어 확장
- 시작 함선 갤리선의 장비는 모든 테크에 장착 가능

## 테크 · 시대 구성 예시
| 테크 | 성격 | 주력 무장 |
|---|---|---|
| 쾌속선 | 빠른 속도 · 선회 | 박치기 · 선수포 · 어뢰 · 유도탄 |
| 다목적함 | 균형형 | 체인샷 · 화염탄 · 폭격 · 선원 |
| 중포함 | 느리지만 튼튼함 | 측면 대포 수 · 피해 감소 · 함재기 |

| 시대 | 쾌속선 | 다목적함 | 중포함 |
|---|---|---|---|
| 0 고대 | 갤리선 (공용 시작 함선) | | |
| 1 대항해시대 | 캐러벨 | 캐랙 | 갤리온 |
| 2 범선 전성기 | 클리퍼 | 프리깃 | 전열함 |
| 3 증기선 시대 | 외륜 증기선 | 증기 프리깃 | 철갑함 |
| 4 강철 군함 | 어뢰정 | 방호 순양함 | 드레드노트 |
| 5 현대 | 미사일 고속정 | 잠수함 | 항공모함 |

- 함선 가격은 시대가 오를수록 큰 폭으로 상승 (예: 1시대 목재 30 · 금화 50, 5시대 목재 700 · 금화 1400)

# 장비
## 기획의도
- 함선마다 슬롯 구성이 달라 함선 개성 형성
- 등급이 높을수록 수치 상승을 넘어 플레이 방식을 바꾸는 고유 효과 부여

## 세부 시스템
- 장비 = 티어 + 장착 가능 테크 + 등급
- 장착 조건: 보유 함선 + 해당 슬롯 보유 + 테크 일치 + 함선 단계 ≥ 장비 티어
- 낮은 티어 장비는 상위 함선에 장착 가능
- 장비 1개당 함선 1척에만 장착, 다른 함선으로 이동 가능
- 일반 · 고급: 함선마다 슬롯별로 그 함선 기술 이름의 장비 (예: 갤리선 "청동 소포", 드레드노트 "14인치 주포")
	- 수치 = 슬롯별 기본 틀 × 티어 배율, 티어가 오를수록 상승폭 증가
- 희귀 · 전설: 함선마다 고유 장비, 일부는 다른 테크에도 장착 가능
- 이름 · 효과에 테크 · 시대 테마 반영 (예: 클리퍼 "쇠뿔 생쥐 선수상" = 박치기, 항공모함 "하늘 치즈성 문장" = 함재기)

## 슬롯 · 등급 예시
| 슬롯 | 주로 올리는 수치 |
|---|---|
| 대포 | 포탄 위력 · 장전 |
| 돛 · 기관 | 속도 · 선회 |
| 선체 장갑 | 선체 · 수리량 |
| 키 | 선회 · 줍기 거리 |
| 망원경 | 치명타 · 사거리 · 시야 |
| 선수상 | 박치기 · 금화 획득량 |
| 박격포 | 폭격 위력 · 범위 |
| 특수탄 창고 | 특수탄 재사용 · 포탄 위력 |
| 선원실 | 최대 선원 수 · 구조 시 수리 |

| 등급 | 성격 | 예시 |
|---|---|---|
| 일반 | 수치 하나 상승 | 포탄 위력 상승 |
| 고급 | 상승폭 증가 또는 두 가지 동시 상승 | 위력 + 장전 동시 상승 |
| 희귀 | 고유 효과 부여 | 착탄 지점 폭발 · 확률 화염 · 확률 체인샷 |
| 전설 | 플레이 방식 변화 | 일제 사격 추가 발사 · 격침 시 회복 · 함재기 추가 |

# 조선소 의뢰
## 기획의도
- 상점 없이 조선공 쥐에게 제작 의뢰 → 재화 소모, 일정 확률로 장비 획득
- 투입 재화를 직접 선택하고 확률을 전부 공개하여 뽑기 거부감 완화
- 현금 결제 없음, 천장(보장) 없음

## 세부 시스템
- 투입 금화를 슬라이더로 결정 (예: 30 ~ 600), 목재는 금화의 일정 비율 함께 소모
- 의뢰 비용은 함선 단계가 오를수록 상승
- 많이 투입할수록 상위 등급 확률 상승, 사이 값은 보간

| 투입 금화 (예시) | 일반 | 고급 | 희귀 | 전설 |
|---|---|---|---|---|
| 30 | 70% | 25% | 4.5% | 0.5% |
| 100 | 45% | 38% | 14% | 3% |
| 250 | 25% | 40% | 27% | 8% |
| 600 | 10% | 35% | 38% | 17% |

- 장비 티어는 현재 함선 단계 기준으로 등장 (예: 현재 단계 60%, 한 단계 아래 25%, 두 단계 아래 10%, 그 아래 5%)
- 보유 함선에 장착 가능한 장비만 등장

# 합성 · 티어 업 · 분해
## 기획의도
- 필요 없는 장비를 재료로 재활용하여 뽑기 실패 부담 완화
- 함선 단계 상승마다 새 도전 목표 발생

## 세부 시스템
- 공통: 장착 중인 장비는 재료로 사용 불가
- 합성: 같은 티어 · 같은 등급 3개 → 한 등급 위 1개
- 티어 업: 같은 티어 전설 여러 개 → 한 티어 위 전설
	- 투입 수가 많을수록 성공 확률 상승 (예: 3개 35%, 4개 50%, 5개 65%, 6개 80%)
	- 실패 시 같은 티어 전설 1개만 반환
	- 한 단계 위 함선 보유 시 도전 가능
- 분해: 장비 1개 → 목재 + 치즈 금화 일부 회수
	- 회수량은 등급 · 티어에 비례 (높은 등급 · 티어일수록 많이 회수)
	- 의뢰 비용보다 적게 회수, 의뢰를 반복하는 쪽이 이득이 되지 않게 조정

# 재화
| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 목재 | 격침 · 보물상자 · 장비 분해 | 함선 구매 · 조선소 의뢰 |
| 치즈 금화 | 격침 · 보물상자 · 콤보 · 장비 분해 | 함선 구매 · 조선소 의뢰 |

- 클리어 시 모은 재화 전부 획득 + 다음 스테이지 개방
- 침몰 시 모은 재화 절반 회수
- 금화 · 목재 보너스 장비로 재화 수급 빌드 가능
- 선원은 인게임 전용 (출항 종료 시 초기화), 아웃게임 재화 아님

# 데이터 테이블
- `Pirat_Table/배 테이블.xlsx`: 함선 (테크 · 시대 · 가격 · 슬롯 · 기본 수치 · 자동 무기), 기본 수치, 테크, 시대, 슬롯 종류
- `Pirat_Table/장비 테이블.xlsx`: 장비 (등급 · 티어 · 장착 테크 · 효과), 등급, 의뢰 확률, 티어 확률, 티어 업 확률, 분해 회수량, 의뢰 설정
- 분해 회수량 (Dismantle 시트): 등급 · 티어별 목재 · 금화 회수량, 초안 = 등급 기본값 × (1 + 0.6 × 티어)
