# 오브젝트
## 기획의도
- 플레이어의 컨트롤 요소를 추가하여 유저에게 컨트롤을 통해 전달되는 피드백의 효용성을 높이고, 스테이지의 클리어를 조금 더 수월하게 조정함

## 세부 시스템
- 맵 내에 파괴 가능한 상자나 부딪히면 데미지를 입는 폭탄 상자 등 장애물 혹은 베네핏이나 은신처로 작동할 수 있는 오브젝트들을 추가함.
- 재화 획득의 기회나 피해야 하는 장애물, 전략적 위치 선점에 도움을 줄 수 있는 오브젝트의 추가로 컨트롤 요소를 강화하고, 유저에게 위치선점의 중요성을 각인시킴.
- 오브젝트는 플레이어와 적 모두에게 똑같이 작용 → 적을 유인해 폭탄 상자 · 은신처 · 해류를 역이용하는 플레이 가능

## 오브젝트 종류 예시
| 오브젝트 | 역할 | 동작 | 플레이어 대응 |
|---|---|---|---|
| 보물상자 | 베네핏 (재화) | 포탄으로 파괴해야 재화 획득 (닿기만 해서는 못 얻음) | 전투 중 틈을 봐서 파괴 |
| 보급 상자 | 베네핏 (아이템) | 포탄으로 파괴 시 사용 아이템 · 소량 재화 드랍 | 위치를 기억해 두고 필요할 때 파괴 |
| 폭탄 상자 | 장애물 · 역이용 | 부딪히면 피해, 포탄으로 터뜨리면 주변 광역 피해 (적 포함) | 피해서 이동, 적 근처에서 터뜨리기 |
| 암초 | 은신처 | 적 포탄 차단, 파괴 불가, 충돌 시 함선 감속 | 뒤로 숨어 장전 시간 확보 |
| 난파선 | 은신처 | 적 포탄 차단, 일정 피해를 받으면 파괴 | 일시적 엄폐, 오래 버티지 못함 |
| 해류 | 컨트롤 | 진입 시 한 방향으로 밀림, 흐름 방향이면 가속 · 역방향이면 감속 | 흐름을 타고 빠르게 이동 · 이탈 |
| 바람 구역 | 컨트롤 | 함선과 포탄이 바람 방향으로 밀림 | 바람을 감안한 조준, 순풍 활용 |

## 배치 규칙
- 무한 맵의 구역 생성 시 섬과 함께 오브젝트 배치, 출발 지점 주변은 비움
- 스테이지마다 오브젝트 구성 비율이 다름 (예: 폭풍 해협 = 바람 구역 많음, 해적 소굴 = 난파선 많음)
- 보물상자: 웨이브마다 일정 수 생성
- 보급 상자 · 폭탄 상자 · 은신처 · 해류 · 바람 구역: 맵 구역 생성 시 고정 배치
- 상세 배치는 스테이지 기획서에서 관리

# 사용 아이템
## 기획의도
- 플레이어의 컨트롤 요소를 추가하여 유저에게 컨트롤을 통해 전달되는 피드백의 효용성을 높이고, 스테이지의 클리어를 조금 더 수월하게 조정함

## 세부 시스템
- 적 또는 상자를 파괴했을 때 일정 확률에 따라 드랍.
- 동시에 하나 이상 소지 불가능
- 원하는 타이밍에 유저의 키 입력에 따라 사용 가능
- 일시적으로 강력한 효과를 부여하여 유저에게 전략적 선택의 재미를 부여하고, 컨트롤을 통한 스테이지 돌파 가능성을 올림.
- 사용 키: F
- 소지 중 새 아이템 획득 시 새 아이템으로 교체 (기존 아이템은 사라짐) → 지금 쓸지 아껴 둘지 고민 유도
- 웨이브 사이에는 유지, 스테이지 종료 시 소멸
- 인게임 전용 시스템. 아웃게임 (함선 · 장비) 과 연결 없음
- 드랍 출처: 적 · 보급 상자
- 드랍된 아이템은 바다 위에 떠 있고, 일정 시간이 지나면 깜빡인 뒤 사라짐

## 사용 아이템 종류 예시
- 무적기: 일정 시간 무적
- 방어막: 공격을 특정 횟수 막아주는 방어막을 획득
- 부스터: 사용 시 빠른 속도로 앞으로 전진(부딪히는 적들에게 공격 부여)
- 포탄 강화: 일정 시간 포탄에 강력한 효과 부여(포탄의 사격 범위 증가, 추가 데미지 등)
- 사격 속도 강화: 일정 시간 포탄 사격 쿨타임 삭제(단, 내부적으론 어느 정도 제한을 둬서 오류 방지)

| 아이템 | 효과 | 쓰기 좋은 상황 |
|---|---|---|
| 무적기 | 일정 시간 모든 피해 무시 | 보스 광역 패턴 · 포위 탈출 |
| 방어막 | 공격을 정해진 횟수만큼 막음 | 측면 사격 대결 · 잠깐 맞으면서 위치 잡기 |
| 부스터 | 짧은 시간 빠르게 전진, 부딪힌 적에게 피해 | 쾌속정 · 상어 무리 돌파, 해류 역방향 탈출 |
| 포탄 강화 | 일정 시간 포탄 범위 · 피해 증가 | 적이 몰려 있을 때, 단단한 철갑함 · 보스 |
| 사격 속도 강화 | 일정 시간 장전 거의 없음 (내부 최소 간격 유지) | 보스 약점 노출 · 상어 지침 타이밍 |

## UI / 연출
- HUD 아이템 슬롯 1칸: 아이콘 + F 키 표시, 비어 있으면 회색
- 사용 중에는 남은 시간 게이지 (방어막은 남은 횟수) 표시
- 함선 주변 효과로 상태 구분 (예: 무적 = 금빛, 방어막 = 하늘색 버블, 부스터 = 뒤쪽 물살 · 불꽃)
- 교체 시 버려진 아이템 아이콘이 짧게 떠올랐다 사라짐
