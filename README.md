# 쥐 비행기 게임 (가제) · 전투 데모

기사 쥐 외전과는 별개 게임, IP(NKK)만 같음. 기획 메모는 [docs/쥐 비행기 게임.md](docs/쥐%20비행기%20게임.md).
슈퍼맨 쥐가 과학자 쥐가 만든 비행기로 하늘을 난다. 적은 연구자료를 노리는 하늘 고양이 · 맹금류.

원래 `C:/Project/nkk_another/plane` 에서 옮겨 옴 (2026-10-27). 여기서 웹 폴리싱 → Unity 이식 예정.

## 실행
```bash
node tools/serve.js
```
→ http://localhost:5321/web/index.html

**단일 HTML** (서버 없이 더블클릭): `node tools/build_single.js` → `build/쥐비행기_전투데모.html`

확인용 주소 (M = 소리 끄기/켜기): `?stage=3` = 그 스테이지, `?wave=4` = 그 웨이브부터(4 = 보스), `&god=1` = 무적, `?go=1` = 제목 화면 건너뜀, `&allstages=1` = 스테이지 다 열기. P · Esc = 일시정지 (창을 벗어나면 자동).

## 전투
- **탑뷰** 자유 공중전. 비행기는 늘 앞으로 날고, **WASD / 방향키 = 날아갈 방향**(그쪽으로 선회), **마우스 = 조준**, 왼쪽 클릭 = 사격(커서 쪽으로), Space = 부스트(게이지)
- **쏘지 않으면 체력 회복**. 하늘에 있는 느낌은 바다 위 그림자 · 위를 지나가는 구름(그림자도 바다에)
- 적: 하늘 고양이(앞질러 겨냥해 3연발, 너무 붙으면 이탈) · 매(빙빙 돌다 → 빨간 점선 + 과녁 예고 → 예고 때 정한 곳으로 급강하, 한 번에 한 마리)
- 제비(빠르게 지그재그로 스쳐 가며 2발) · 폭격 고양이(느리고 단단, 조준 3갈래 + 원형탄)
- 떨어뜨리는 재료 · 일반 적 체력 · 받는 피해는 스테이지 `mult` 배율
- 떨어뜨리는 것: 톱니(재료) · 치즈 코인(재화) · 렌치(체력 25%). 클리어하면 전부 + 다음 스테이지 열림, 추락하면 절반이 격납고로
- **스테이지 5개는 `web/stages.js`** (배경 · 웨이브 · 보스 · 난이도 배율 · 추천 단계). 새 배경 종류(`bg.type`)는 `web/backgrounds.js` 에 그리기 추가

| 스테이지 | 배경 | 보스 | 보스 패턴 (`game.js` 의 `BOSS`) |
|---|---|---|---|
| 1 바다 위 하늘 | 바다 · 섬 | 고양이 비행선 | 대포 두 문 → 나선 탄막 → 원형 탄 + 졸개 고양이 |
| 2 폭풍 구름 위 | 구름바다 · 번쩍임 | 천둥 독수리 | 깃털 부채 → 번개(예고선 뒤 내리침) → 급강하 돌진(지나간 자리에 깃털) |
| 3 눈 덮인 산맥 | 설산 · 숲 · 호수 | 눈보라 부엉이 | 눈꽃 이중 나선 → 유도 얼음 구슬 → 눈보라(바람에 밀림 + 틈 하나 있는 얼음 벽) |
| 4 고양이 도시의 밤 | 도시 지붕 · 가로등 · 네온 | 고양이 공중 전함 | 포탑 4문 → 측면 일제 사격 → 함수 주포 광선(예고 뒤 휩쓸기) |
| 5 성층권 너머 | 우주 · 별 · 소행성 | 고양이 대왕 로켓 | 체력 3구간: 꽃 탄막 · 번개 → 번개 · 유도탄 · 졸개 → 회전 광선 4줄 · 원형 연발 |

- 보스는 체력 절반부터 더 빠르고 졸개를 부름. 패턴이 바뀔 때 화면 위에 예고 문구
- 위험 지대(`S.hz`): 번개 · 광선 = 예고선(붉은 점선)이 진해진 뒤 터짐. 바람(`S.wind`) = 플레이어를 밀어냄
- 수치는 `web/upgrades.js` 의 `BASE`(플레이어) · `web/game.js` 의 `FOE`(적)

## 격납고 (아웃게임 강화) — `web/upgrades.js` 데이터 · 저장, `web/hangar.js` 화면
- **비행기 진화** = 실제 비행기 발전 순서, 4단계 × 2갈래 (위 = 빠른 전투기, 아래 = 튼튼한 폭격기)
  - 0 복엽 글라이더 → 1 단엽 전투기 / 쌍발 중전투기 → 2 후퇴익 제트기 / 4발 중폭격기 → 3 초음속 델타익기 / 전익 전략폭격기
  - 부모 기체를 가져야 다음 기체를 삼. 산 기체는 언제든 바꿔 탈 수 있음
- 격납고 탭 3개: **기체**(진화 트리) · **장비**(기체별 슬롯에 끼우기) · **연구소**(과학자 쥐 제작 의뢰 · 합성). 설계 = [docs/장비_제작의뢰.md](docs/장비_제작의뢰.md)
- **장비는 기체 전용**: 기체마다 슬롯 구성이 다름 (`FRAMES.slots`, 3~6칸 — 엔진 · 주무장 · 날개 · 장갑 · 조준기 · 기수포 · 레이더 · 유도탄 · 폭탄창 · 기총탑 · 특수 장치)
  - 일반 · 고급 = 수치만 (`TEMPLATE` 틀 × 기체 단계), 희귀 · 전설 = 고유 효과 장비 (`UNIQUE`, 기체마다 희귀 2 · 전설 1). 모두 87종
  - 장착 상태는 기체마다 따로 저장, 아직 없는 기체에도 미리 끼워 둘 수 있음
- **제작 의뢰**: 쓸 코인을 슬라이더로 고름(톱니는 1/3) → 많이 쓸수록 높은 등급 확률 ↑ (`ODDS`, 화면에 확률 표시). 나오는 장비는 모든 기체 통틀어 완전 랜덤
- **합성**: 같은 등급 3개(장착 안 한 것) → 한 등급 위 장비 하나, 완전 랜덤
- 고유 효과 · 새 무기(기수포 · 폭탄 · 기총탑 · 레일건 · 충격파 …)는 `BASE` 아래쪽 값 → `game.js` 의 `dmgFoe` · `dropBomb` · `railShot` 등
- 수치 계산: `BASE` → 기체 · 장비 `add` → `mul`. 장비에 마우스 / 다른 기체 선택 = 수치 차이 미리보기
- 저장 = localStorage `ratplain_save_v2` (v1 저장은 산 파츠 값을 재화로 돌려주고 옮김). 확인용: `?hangar=1` · `?hangar=gear` · `?hangar=lab` = 격납고 그 탭부터, `&rich=1` = 재료 9999
- 그림: 기체 = `art/sprites/player_<id>_0.png`, 장비 아이콘 = `parts_a/b/c` · 고유 장비 `parts_u1~u3` 시트, 연구소 = `scientist` (프롬프트 `art/src/prompt_*.txt`).
  전용 그림이 없으면 벡터 임시 그림(아래), 그것도 없으면 기본 비행기에 색 필터 · 크기(`tint` · `scale`)
