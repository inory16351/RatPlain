# 쥐 비행기 게임 (가제) · 전투 데모

기사 쥐 외전과는 별개 게임, IP(NKK)만 같음. 기획 메모는 [docs/쥐 비행기 게임.md](docs/쥐%20비행기%20게임.md).
슈퍼맨 쥐가 과학자 쥐가 만든 비행기로 하늘을 난다. 적은 연구자료를 노리는 하늘 고양이 · 맹금류.

원래 `C:/Project/nkk_another/plane` 에서 옮겨 옴 (2026-10-27). 여기서 웹 폴리싱 → Unity 이식 예정.

## 실행
```bash
node tools/serve.js
```
→ http://localhost:5321/web/index.html

**단일 HTML** (서버 없이 더블클릭): `node tools/build_single.js` → `build/쥐비행기_전투데모.html`

확인용 주소 (M = 소리 끄기/켜기): `?stage=3` = 그 스테이지, `?wave=4` = 그 웨이브부터(4 = 보스), `&god=1` = 무적, `?go=1` = 제목 화면 건너뜀, `&allstages=1` = 스테이지 다 열기, `&allframes=1` = 기체 다 갖기. P · Esc = 일시정지 (창을 벗어나면 자동).

## Unity 이식 · MCP 연결
`unity/` = Unity 프로젝트 자리(아직 빈 껍데기). Claude Code 가 Unity 에디터를 직접 만지도록 [MCP for Unity](https://github.com/CoplayDev/unity-mcp) (v10.3.0) 를 미리 넣어 둠.

1. 준비: Unity 2021.3 LTS ~ 6.x, Python 3.10+ 과 [`uv`](https://docs.astral.sh/uv/) (`uv --version` 이 돼야 함)
2. Unity Hub → Add project from disk → `unity/` 폴더 → 원하는 에디터 버전으로 열기 (패키지는 `unity/Packages/manifest.json` 에서 자동 설치)
3. Unity 에서 `Window → MCP for Unity` → 서버 시작 (HTTP, `localhost:8080`)
4. 이 저장소 루트에서 `claude` 실행 → 루트 `.mcp.json` 의 `unityMCP` 를 승인 → `/mcp` 에서 connected 확인

연결이 안 되면 `Window → MCP for Unity` 의 상태 칸, 포트(8080)가 `.mcp.json` 주소와 같은지 확인. 2D 렌더러 · UGUI · Input System 같은 패키지는 에디터 버전에 맞춰 Package Manager 로 추가.

## 전투
- **탑뷰** 자유 공중전. 비행기는 늘 앞으로 날고, **WASD / 방향키 = 날아갈 방향**(그쪽으로 선회), **마우스 = 조준**, 왼쪽 클릭 = 사격(커서 쪽으로), Space = 부스트(게이지)
- **쏘지 않으면 체력 회복**. 하늘에 있는 느낌은 바다 위 그림자 · 위를 지나가는 구름(그림자도 바다에)
- 적: 하늘 고양이(앞질러 겨냥해 3연발, 너무 붙으면 이탈) · 매(빙빙 돌다 → 빨간 점선 + 과녁 예고 → 예고 때 정한 곳으로 급강하, 한 번에 한 마리)
- 제비(빠르게 지그재그로 스쳐 가며 2발) · 폭격 고양이(느리고 단단, 조준 3갈래 + 원형탄)
- 고양이 드론(떼로 와서 멈칫 · 깜빡 예고 뒤 자폭 돌진) · 장갑 포함(`FOE.armor` = 주무장 피해 70% 깎임, 폭탄 · 기수포 · 유도탄 · 레일건 · 철갑탄은 그대로, 터지는 대공포탄)
- 떨어뜨리는 재료 · 일반 적 체력 · 받는 피해는 스테이지 `mult` 배율
- 떨어뜨리는 것: 톱니(재료) · 치즈 코인(재화) · 렌치(체력 25%). 클리어하면 전부 + 다음 스테이지 열림, 추락하면 절반이 격납고로
- **스테이지 10개는 `web/stages.js`** (배경 · 웨이브 · 보스 · 난이도 배율 · 추천 단계 · 추천 갈래 · 맵 특성 `trait`). 새 배경 종류(`bg.type`)는 `web/backgrounds.js` 에 그리기 추가

## 격납고 (아웃게임 강화) — `web/upgrades.js` 데이터 · 저장, `web/hangar.js` 화면
- **비행기 진화** = 실제 비행기 발전 순서, 6단계(0~5) × 3갈래 = 16대 (`FRAMES.line`: F 위 = 빠른 전투기, M 가운데 = 다목적기, B 아래 = 튼튼한 폭격기)
  - F: 단엽 전투기 → 후퇴익 제트기 → 초음속 델타익기 → 스텔스 전투기 → 우주 요격기
  - M: 급강하 폭격기 → 제트 전폭기 → 가변익 다목적기 → 무인기 지휘기(호위 무인기) → 궤도 왕복 공격기
  - B: 쌍발 중전투기 → 4발 중폭격기 → 전익 전략폭격기 → 극초음속 폭격기 → 공중 항공모함
  - 부모 기체를 가져야 다음 기체를 삼. 산 기체는 언제든 바꿔 탈 수 있음. **테크** = 가진 기체의 최고 단계
- 격납고 탭 3개: **기체**(진화 트리) · **장비**(기체별 슬롯에 끼우기) · **연구소**(과학자 쥐 제작 의뢰 · 합성). 설계 = [docs/장비_제작의뢰.md](docs/장비_제작의뢰.md)
- **장비 = 티어 · 등급 · 낄 수 있는 갈래가 따로** (`PARTS.tier` · `grade` · `lines` → `fits`). 기체마다 슬롯 구성이 다름 (`FRAMES.slots`, 3~7칸 — 엔진 · 주무장 · 날개 · 장갑 · 조준기 · 기수포 · 레이더 · 유도탄 · 폭탄창 · 기총탑 · 무인기 · 특수 장치)
  - 장착 조건: **가진 기체** + 그 슬롯이 있음 + 갈래가 맞음 + **기체 단계 ≥ 장비 티어** (낮은 티어 장비는 높은 기체에 OK, 반대는 안 됨). 한 장비는 한 기체에만 (다른 기체로 옮기기 가능)
  - 일반 · 고급 = 수치만 (`TEMPLATE` 틀 × 티어), 희귀 · 전설 = 고유 효과 장비 (`UNIQUE`, 기체 기술마다 희귀 2 · 전설 1). 모두 224종
- **제작 의뢰**: 쓸 코인을 슬라이더로 고름(톱니는 1/3, 비용 × 테크 배율 `reqK`) → 많이 쓸수록 높은 등급 확률 ↑ (`ODDS`). 티어는 테크 기준 `tierOdds`(테크 60% · −1 25% · −2 10% · 나머지 5%). **가진 기체에 낄 수 있는 장비만** 나옴. 확률은 화면에 표시
- **합성**: 같은 티어 · 같은 등급 3개(장착 안 한 것) → 같은 티어 한 등급 위 장비 하나 (랜덤)
- **티어 업 도전**: 같은 티어 전설 3~6개 → 한 티어 위 전설 (3개 35% · 4개 50% · 5개 65% · 6개 80%). 실패하면 같은 티어 전설 하나만 남음. 한 단계 위 기체가 있어야 도전 가능 → 테크를 올릴 때마다 다시 뽑기 · 도전
- 고유 효과 · 새 무기(기수포 · 폭탄 · 기총탑 · 레일건 · 충격파 …)는 `BASE` 아래쪽 값 → `game.js` 의 `dmgFoe` · `dropBomb` · `railShot` 등
- 수치 계산: `BASE` → 기체 · 장비 `add` → `mul`. 장비에 마우스 / 다른 기체 선택 = 수치 차이 미리보기
- 저장 = localStorage `ratplain_save_v2` (v1 저장은 산 파츠 값을 재화로 돌려주고 옮김). 확인용: `?hangar=1` · `?hangar=gear` · `?hangar=lab` = 격납고 그 탭부터, `&rich=1` = 재료 9999
- 그림: 기체 = `art/sprites/player_<id>_0.png`, 장비 아이콘 = `parts_a/b/c` · 고유 장비 `parts_u1~u3` 시트, 연구소 = `scientist` (프롬프트 `art/src/prompt_*.txt`).
  전용 그림이 없으면 벡터 임시 그림(아래), 그것도 없으면 기본 비행기에 색 필터 · 크기(`tint` · `scale`)
