## 기획의도
- 원작의 가볍고 캐쥬얼한 감성을 살린 ip 확장 게임. 쥐 비행기 게임의 자매작
- 원작 해적 쥐(애꾸 · 삼각모)를 따 와서 바다로 ip 확장. 본편과는 별개 게임, 캐릭터와 그림체만 공유
- 인게임 = 쥐 해적선 프로토타입(`RatPirate/index.html`) 조작 · 전투 그대로 유지
- 아웃게임 = 쥐 비행기 게임 구조(테크 갈래 분기 + 티어 · 등급 장비, 의뢰 · 합성 · 티어 업) 그대로 배에 맞게 변환
- 실제 배 발전 순서대로 진화 (갤리선 → 범선 → 증기선 → 강철 군함 → 현대 함정) → 모으는 재미 + 눈에 보이는 변화
- 뱃전 일제 사격 = 옆구리를 적에게 돌려야 쏨 → 비행 슈팅과 다른 "배 몰기" 조작 재미

## 원페이지 기획서
| 항목 | 내용 |
|---|---|
| 제목 | 쥐 해적 — 바다 정복 (가제) |
| 장르 | 탑뷰 해전 액션 (웨이브 + 보스) |
| 플랫폼 | 웹게임(PC 키보드 + 마우스) → 이후 Unity 이식 |
| 타겟 | 원작 팬, 쥐 비행기 게임 유저, 캐쥬얼 액션 유저 |
| 볼륨 | 바다 8, 보스 5종(강화판 포함 8전), 배 16척, 장비 213종 |
| 적 | 고양이 해군 · 라이벌 쥐 해적 · 상어 |

- 바다 흐름: 치즈 항구 앞바다 → 상어 암초 → 고양이 해군 순찰대 → 안개 낀 해적 소굴 → 폭풍 해협 → 철갑 함대 → 소용돌이 바다 → 고양이 해군 본진
- 배도 노 젓는 갤리선 → 항공모함 · 잠수함 · 미사일 고속정 순으로 변화

## 스토리
- 주인공: 원작 해적 쥐 "애꾸 선장" (애꾸 안대 · 삼각모 · 빨간 코트)
- 고양이 해군에게 빼앗긴 바다를 되찾고 일곱 바다를 정복하겠다는 야망
- 첫 배 = 애꾸 선장이 처음 훔친 노 젓는 갤리선 "찍찍 1호"
- 적 세력
	- 고양이 해군: 바다를 장악한 정규군. 순찰선 → 철갑 함대 → 대제독 해상 요새까지 점점 강해짐
	- 라이벌 쥐 해적: 같은 쥐지만 바다를 노리는 경쟁자. 항해사 '회색꼬리', 해적왕 블랙랫
	- 상어: 어느 세력에도 속하지 않는 바다의 위협. 물속에 숨어 지느러미만 보임
- 처음 켜면 스토리 화면 → 애꾸 선장의 다짐. 바다마다 짧은 스토리 문구
- 최종 목표 = 고양이 해군 본진의 대제독 해상 요새 격침

## 핵심 재미
- 배를 모는 손맛: 돛으로 속도, 키로 방향 조절. 옆구리를 적에게 돌려 일제 사격하는 위치 잡기가 곧 실력
- 한 방의 쾌감: 뱃전 대포 여러 문이 한 번에 터지는 일제 사격, 콤보, 히트스톱, 화면 흔들림
- 구하면 강해지는 배: 물에 빠진 쥐를 건지면 선원 증가 → 장전 빨라짐 + 갑판에 선원이 늘어나는 게 보임
- 진화하는 배: 갤리선에서 항공모함까지 실제 배 역사 순서로 성장. 단계마다 자동 무기가 붙어 전투 양상 변화

## 게임 루프
- 판 안: 웨이브 3개 → 보스 웨이브 → 승리 보상. 웨이브 사이 수리
- 판 밖(항구): 목재 / 치즈 금화로 배 구매, 조선소 의뢰, 합성 → 바다 특성에 맞는 배 선택 → 재출항
- 침몰해도 모은 재화 절반 회수. 다시 출항할 이유 유지
- 바다 클리어 시 다음 바다 개방

## 인게임 시스템
### 조작 / 전투
- 원본 프로토타입 조작 그대로

| 입력 | 동작 |
|---|---|
| W / S | 돛 올리기 · 내리기 (속도) |
| A / D | 키 (방향 전환) |
| 왼쪽 클릭 (누르고 있으면 연사) | 마우스 쪽 뱃전 일제 사격 |
| Q / E | 왼쪽 / 오른쪽 뱃전 일제 사격 |
| Space | 양쪽 뱃전 동시 사격 |
| 1 | 체인샷: 적 돛을 찢어 느리게 |
| 2 | 화염탄: 불붙여 지속 피해 |
| 3 | 폭격: 마우스 위치 광역 폭발 |

- 특수탄 · 폭격은 배 · 장비에 해당 값이 있을 때만 사용 가능 (값 = 재사용 초)
	- 체인샷: 캐랙부터 (9초) / 화염탄: 프리깃부터 (10초) / 폭격: 증기 프리깃부터 (13초)
- 뱃전 쿨다운은 좌우 따로. 대포 수 = 뱃전 한쪽 대포 수
- 수치는 조선소 계산 결과 사용: 대포 수 · 장전 · 위력 · 치명타 · 사거리 · 속도 · 회전 · 선체 · 받는 피해
- 기본값: 선체 100, 속도 170, 대포 2문, 장전 2.1초, 위력 14, 치명타 10%, 웨이브 사이 수리 15
- 선원 구조: 격침된 배에서 쥐가 물에 빠짐 → 지나가며 건지면 선원 +1
	- 선원 1명당 장전 −2% (최대 12명분, 배 · 장비로 확장)
	- 웨이브가 끝나면 못 건진 선원도 전부 합류
- 콤보: 2.5초 안에 연속 격침 시 이어짐. 5콤보마다 금화 +10%
- 떨어뜨리는 것: 치즈 금화 · 목재 · 보물상자 · 납치된 쥐(구조 = 선원 +1)
- 바다 · 섬 · 물살 · 파편 · 콤보 · 히트스톱 연출은 원본 코드 그대로 이식

### 자동 무기
- 배 단계가 오르면 자동 무기가 붙음 → 조작 부담은 그대로, 화력만 추가

| 자동 무기 | 동작 | 처음 붙는 배 |
|---|---|---|
| 선수포 | 앞 45° 안 가까운 적에게 직사 | 외륜 증기선 · 방호 순양함 · 철갑함 |
| 어뢰 | 마우스 쪽으로 곧게 달림, 잠수한 상어도 맞음 | 어뢰정 · 잠수함 |
| 유도탄 | 적을 따라가는 유도 사격 | 미사일 고속정 |
| 함재기 | 배 둘레를 돌며 가까운 적 사격 (최대 8대) | 항공모함 |
| 자동 폭격 | N초마다 가장 가까운 적에게 폭격 | 장비(자동 폭격 지휘 · 하늘 치즈성 문장) |

- 고유 효과(희귀 · 전설 장비): 박치기 · 포탄 폭발 · 전탄 화염 · 전탄 체인샷 · 일제 사격 한 번 더 · 격침 시 회복 · 빗나감 · 크라켄 묶기 · 폭풍 저항 · 금화 / 목재 보너스 · 구조 시 수리
- 빗나감 최대 50%, 폭풍 저항 최대 90%로 제한

### 선원 리깅
- 배 그림과 선원 그림을 분리. 배 갑판은 비워 두고 선원 스프라이트를 코드로 올림
- 배 길이 비율 좌표(선원 자리)마다 선원 배치 → 배 16척 모두 같은 방식
- 선장(애꾸 선장): 고물 쪽 고정. 평소 서 있음, 쏠 때 칼로 가리킴
- 건진 선원 수만큼 갑판에 선원 증가 (최대 7명 표시) → 선원 수가 눈으로 보임
- 쏘면 선원이 살짝 튐 + 흔들림. 가라앉으면 선원이 바다로 뛰어내림
- 고양이 배 = 고양이 수병, 보스 = 전용 선장 (제독 · 해적왕 · 대제독 · 라이벌 선원)
- 장점: 배 그림 하나로 선원 수 변화 · 반응 연출 가능, 그림 생성 수 감소

| 프리깃 | 고양이 해군 | 대포 많은 일제 사격 | 체인샷으로 늦춘 뒤 측면 사격 |
| 쾌속정 | 고양이 해군 | 빠르게 달려와 박치기 | 키 꺾어 회피, 선수포 · 박치기 장비 |

### 상어 잠수
- 평소엔 지느러미만 보이는 잠수(버로우) 상태 + 물살
- 잠수 중 포탄은 위로 지나감 → 어뢰 · 폭격만 맞음
- 가까이 오면 떠올라 2.5초 동안 몸 보이고 물기 → 다시 잠수
- 대처 = 떠오른 순간 일제 사격 / 어뢰 · 폭격 갈래 배로 잠수 중에도 공격
- 지느러미 그림 2종 (일반 상어 · 거대 상어)

### 바다 / 보스
- 바다 구성: 웨이브 3개 + 보스 웨이브. 웨이브 사이 수리 + 선원 수만큼 추가 수리
- 바다 배율 = 적 체력 × 배율, 적 피해 × (1 + (배율 − 1) × 0.6)

## 아웃게임 시스템
### 배 진화
- 실제 배 발전 순서대로 6시대 × 3갈래 = 16척
- 시대: 0 고대 → 1 대항해시대 → 2 범선 전성기 → 3 증기선 시대 → 4 강철 군함 → 5 현대
- 부모 배 보유 시 다음 배 구매 가능. 구매한 배는 자유롭게 교체
- 테크 = 보유 배 최고 단계

| 갈래 | 성격 | 진화 |
|---|---|---|
| 쾌속선 (S) | 빠르고 잘 돎, 박치기 · 선수포 · 어뢰 · 유도탄 | 캐러벨 → 클리퍼 → 외륜 증기선 → 어뢰정 → 미사일 고속정 |
| 다목적함 (M) | 균형형, 체인샷 · 화염탄 · 폭격 · 선원 | 캐랙 → 프리깃 → 증기 프리깃 → 방호 순양함 → 잠수함 |
| 중포함 (H) | 느리고 튼튼함, 대포 많음 · 피해 감소 | 갤리온 → 전열함 → 철갑함 → 드레드노트 → 항공모함 |

- 시작 배: 갤리선 "찍찍 1호". 이 배의 장비는 모든 갈래에 장착 가능

| 시대 | 배 (이름) | 갈래 | 가격 (목재 / 금화) | 선체 | 속도 | 뱃전 대포 | 특징 |

### 장비
- 장비 = 티어 + 장착 가능 배(갈래) + 등급
- 장착 조건: 보유 배 + 해당 슬롯 보유 + 갈래 일치 + 배 단계 ≥ 장비 티어. 낮은 티어 장비는 상위 배에 장착 가능
- 장비 1개당 배 1척에만 장착 (다른 배로 이동 가능)
- 총 213종: 일반 90 · 고급 90 · 희귀 17 · 전설 16
- 일반 / 고급 = 배마다 그 배 기술 이름으로 자동 생성 (예: 갤리선 "청동 소포", 드레드노트 "14인치 주포"). 수치 = 틀 × 티어 배율(1 + 0.35 × 티어)
- 희귀 / 전설 = 배마다 2종 고유 장비 (갤리선 3종). 일부는 다른 갈래에도 장착 가능
- 등급별 성격
	- 일반: 수치 하나 상승 (예: 대포 = 포탄 위력)
	- 고급: 상승폭 증가 또는 두 가지 동시 상승 (예: 대포 = 위력 + 장전)
	- 희귀: 고유 효과 시작 (예: 작렬 포탄 = 포탄이 맞은 곳 폭발, 그리스의 불 = 모든 포탄 20% 불붙임)
	- 전설: 플레이 방식 변화 (예: 회전 포탑 쌍열포 = 일제 사격 50% 한 번 더, 쥐 해병대 = 격침 시 회복)
- 대표 고유 장비

| 장비 | 등급 | 배 | 효과 |
|---|---|---|---|
| 애꾸 선장의 첫 배 판자 | 전설 | 갤리선 | 선체 +40, 격침 시 체력 4% 회복 |
| 갈고리 체인샷 | 희귀 | 캐랙 | 모든 포탄 15% 체인샷 |
| 쇠뿔 생쥐 선수상 | 희귀 | 클리퍼 | 박치기 60 |
| 애꾸 망원경 | 전설 | 프리깃 | 치명타 +18%, 사거리 +12%, 안개 시야 +200 |
| 크라켄 촉수 체인 | 희귀 | 방호 순양함 | 체인샷 적중 시 주변 적 2초 묶음 |
| 쥐 귀 위상 레이더 | 전설 | 미사일 고속정 | 치명타 +20%, 빗나감 12%, 사거리 +15%, 시야 +300 (전 갈래) |
| 하늘 치즈성 문장 | 전설 | 항공모함 | 함재기 +2, 4초마다 자동 폭격, 격침 시 체력 5% 회복 |

### 조선소 의뢰 / 합성 / 티어 업
- 상점 없음. 조선소에 제작 의뢰 → 재화 소모, 일정 확률로 장비 획득
- 투입 금화를 슬라이더로 결정 (30~600, 10 단위). 목재는 금화의 1/3. 비용 × 테크 배율(1 + 0.6 × 테크)
- 많이 쓸수록 상위 등급 확률 증가. 확률은 화면에 그대로 공개 (사이 값은 로그 보간)

| 투입 금화 | 일반 | 고급 | 희귀 | 전설 |
|---|---|---|---|---|
| 30 | 70% | 25% | 4.5% | 0.5% |
| 100 | 45% | 38% | 14% | 3% |
| 250 | 25% | 40% | 27% | 8% |
| 600 | 10% | 35% | 38% | 17% |

- 티어는 테크 기준 (테크 60%, −1 25%, −2 10%, 나머지 5%)
- 보유 배에 장착 가능한 장비만 등장
- 합성: 같은 티어 / 같은 등급 3개 → 한 등급 위 1개 (장착 중인 장비 제외)
- 티어 업: 같은 티어 전설 3~6개 → 한 티어 위 전설

| 투입 전설 | 3개 | 4개 | 5개 | 6개 |
|---|---|---|---|---|
| 성공 확률 | 35% | 50% | 65% | 80% |

- 실패 시 같은 티어 전설 1개만 남음
- 티어 업은 한 단계 위 배 보유 필요 → 테크 상승마다 새 의뢰 / 도전 목표 발생

### 재화 순환
| 재화 | 얻는 곳 | 쓰는 곳 |
|---|---|---|
| 목재 | 격침 · 보물상자 | 배 구매, 의뢰 (금화의 1/3) |
| 치즈 금화 | 격침 · 보물상자 · 콤보 보너스 | 배 구매, 의뢰 |
| 선원 | 물에 빠진 쥐 · 납치된 쥐 구조 | 판 안 장전 단축 · 수리 (판 종료 시 소멸) |

- 항해 끝: 승리 = 모은 재화 전부 + 다음 바다 개방, 침몰 = 절반
- 금화 / 목재 보너스 장비 (황금 쥐 선수상, 치즈 창고 선체 등)로 재화 수급 빌드 가능
- 흐름: 출항 → 재화 획득 → 배 구매 · 의뢰 → 테크 상승 → 상위 티어 장비 등장 → 다음 바다

## 비쥬얼 가이드
- NKK 원본의 플랫하고 귀여운 그림체 유지. Codex 로 새로 생성
- 차분한 색: 채도 낮은 자연색(나무 갈색 · 크림 · 탁한 빨강 / 파랑), 큰 면, 소품 최소 (통 · 상자 · 밧줄 · 등불 없음), 외곽선 · 광택 · 그라데이션 없음
	- 이전 쥐 해적 그림은 채도 높고 소품 많아 그림체 불일치 → 프롬프트에 반영함
- 그림은 전부 탑뷰, 뱃머리 오른쪽 (회전은 코드 처리)
- 배 그림만 봐도 쥐 · 고양이 구분 가능해야 함 (작게 봐도 읽히는 큰 형태)

- 포탄 · 연기 · 물살은 벡터 이펙트, 위험 요소는 예고선 / 예고 원으로 표시
